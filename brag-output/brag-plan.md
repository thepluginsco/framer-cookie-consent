# Brag Plan: Consentful

## What is it?
Consentful is a cookie-consent banner that actually blocks trackers until the visitor says yes, for Framer, Webflow, WordPress, Shopify, Wix and any HTML site.

## Reference
Zelios "StoreTrack" explainer (youtu.be/M8tXsQ34f30). Motion vocabulary borrowed:
pain-point pills piling up under a slow camera push, word-by-word kinetic type with bold emphasis,
icon-pop + letter-stagger logo build, circle iris wipe into a brand-colour field with orbiting chips,
real UI in a browser window with a cursor and camera punch-ins, "-> Option" customise carousel, logo outro.

## The angle
"Most banners ask. Consentful enforces." (the site's own line). Open on trackers firing before anyone consented,
then show the product holding them until the click.

## Hook (0-3s)
Tracker pills pile up: "Google Analytics fired", "Meta Pixel loaded", "Nobody said yes."

## Highlights
1. One banner, every platform (orbiting platform chips).
2. The product in use: banner on yourbrand.com, trackers Held -> click Accept all -> Live, Consent Mode v2 denied -> granted, receipt toast.
3. Design it like it's part of your site: theme, accent, corners.

## Outro
Logo build + "Cookie consent that actually blocks the cookies." + consentful.theplugins.co

## Tone
default / polished-playful. 120 BPM, cuts on the beat.

## Visual identity
- Indigo-violet #4b23d3, deep indigo #2a0e6e, night #1b0b47, lavender #f1edfe
- Iris gradient (pink, peach, cream, mint, lavender) for signature moments
- Plus Jakarta Sans, JetBrains Mono
- Real assets: mascot, cookie-with-shield banner hero; banner CSS mirrors runtime/src/styles.ts
